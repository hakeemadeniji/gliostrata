## 2. The three variants and what each measures

All three use the same estimator (`gliostrata.prediction.cox.CoxPHModel`, Breslow partial
likelihood, ridge 1e-6), fitted on TCGA-GBM and scored with Harrell's C-index on CGGA. Only
the features differ.

### 2.1 Variant 1: the committed baseline (age, sex, KPS, treatment_arm)

`fit_clinical_baseline` exactly as committed: 594 patients passed to the fit, 592
modelled, median-indicator imputation, 5-fold stratified CV, pooled out-of-fold C-index.
This is the model T2 was registered against.

**What the imputation does, in numbers.** KPS is missing for 150 of the 592 modelled
patients; each is set to the TCGA median, 80, and a `kps_missing` indicator is added. That
indicator is prognostic in its own right: hazard ratio 1.57 (section 3), so "KPS was never
recorded" carries information the model uses. The treatment arm is missing for 22 patients
and is coded as its own level (hazard ratio 1.20). Nothing else is imputed: age and sex are
complete. There are 491 deaths among the 592. Until 2026-11-27 the median was computed on
all modelled patients before the folds were drawn; it is now taken from each fold's
training rows, which changed no number (section 4.2, note). The counts are pinned by
`tests/fixtures/tcga_fit_fingerprint.json`.

The words "nothing is imputed" in this document and in the script apply to the CGGA side
and to variants 2 and 3. Variant 1 is never scored on CGGA, so no imputed KPS enters any
external number.

**It cannot be validated on CGGA.** CGGA publishes no performance status in any of its
three clinical files: `kps` is null for all 333 rows (`docs/cgga_ingestion.md` section 4).
KPS was not imputed. An imputed KPS would be a TCGA median pasted onto Chinese patients
and scored as if it were an observation; the number would describe the imputation, not
the model.

The finding for variant 1 is therefore: **the registered T2 model is untestable on the
registered external cohort.** That is a feature-divergence problem, not a performance
result.

### 2.2 Variant 2: the transferable model (age, sex, treatment_arm)

The largest strict subset of the committed feature set that both cohorts record. It
measures how much of the committed model's discrimination survives when KPS is removed
and nothing is added. It was pre-specified as the headline because it is the closest
thing to the registered model that can be scored on CGGA at all.

- Fitted on the 570 TCGA patients with all three features and an observed outcome (594
  minus 23 without a treatment arm, minus 1 without a vital status).
- Scored on the 283 CGGA patients with all three features and an observed outcome (239
  deaths).

### 2.3 Variant 3: the maximal shared molecular model

Variant 2 plus IDH mutation status and MGMT promoter methylation. It measures whether
the two molecular markers both cohorts annotate add external discrimination.

- Fitted on the 298 TCGA patients with all five features and an outcome, using the joined
  TCGA calls (`data/processed/tcga_gbm/molecular_calls_joined.parquet`, commit 320707c).
  A missing call is excluded, never read as wildtype.
- Scored on 241 CGGA patients, using CGGA's own IDH and MGMT annotations.

It is **cross-platform**: the two cohorts' marker calls come from different sources and need
not be equivalent (section 5).

## 4. Reading the result

### 4.1 Variant 2 is below 0.55: the model is not transferring

The headline external C-index is **0.5385** (95% CI 0.4994 to 0.5807, n = 283, 239 deaths).

- It is below the pre-registered 0.65, and the **entire interval** is below it. This is
  not a near miss that a larger sample would be expected to rescue.
- It is below 0.55. A C-index of 0.5 is a coin flip; at 0.5385 the model ranks a CGGA
  patient's risk only slightly better than chance.
- The interval **contains 0.50**. These data do not establish that the model discriminates
  at all in CGGA. They also do not establish that it cannot: the upper bound, 0.581, is
  consistent with weak discrimination.

The honest summary is the second point, bounded by the third: the TCGA-fitted clinical
model shows, at best, weak discrimination in CGGA that is statistically
indistinguishable from chance. "Missed the 0.65 bar" understates it; "proven useless"
overstates it.

### 4.2 Where the gap sits: two contrasts, both descriptive

Variants 1 and 2 are both scored internally on TCGA, so three C-indices are on record:

| Step | C-index | Difference (no interval) |
| --- | --- | --- |
| Committed baseline, TCGA (4 features) | 0.6735 | |
| Transferable model, TCGA (3 features) | 0.6520 | -0.0215 |
| Transferable model, CGGA (same 3 features) | 0.5385 | -0.1135 |

**Neither difference carries an interval.** Neither was bootstrapped. What follows is a
description of three numbers, not an attribution with uncertainty.

The first contrast is not "the effect of KPS". Variant 1 against variant 2 changes three
things at once:

- the KPS value itself;
- a missing-KPS indicator that is prognostic in its own right (hazard ratio 1.57, for 150
  of the 592 modelled patients);
- the fit set: 592 modelled patients with imputation, against 570 complete cases.

The 0.0215 is the net of those three and is not an estimate of what KPS is worth.

The second contrast is a like-for-like comparison of one fitted model on two cohorts:
-0.1135. Read descriptively, it is about five times the first. That ordering is consistent
with the shortfall lying mainly in the move between cohorts rather than in the loss of KPS.
It does not show it. The one-line explanation "the model fell short because CGGA has no
KPS" is neither confirmed nor excluded by these numbers.

Note (2026-11-27). Variant 1's internal C-index was recomputed with the imputation done
inside each cross-validation fold, as the code had said it did: 0.673544 before and after,
because every training fold's median KPS is 80. The 0.6735 quoted here is unchanged.

What causes the second step is **not established**, and finding out would mean more reads
of CGGA. Candidate explanations, all untested:

- **A different population and care pathway.** CGGA is a Chinese cohort with a median age
  of 52 against TCGA-GBM's 59 (`docs/cgga_ingestion.md` section 6.2). Age is one of only
  three predictors in variant 2 (TCGA HR 1.033 per year), and a C-index depends on how a
  predictor is spread in the target population, not only on its coefficient.
- **`treatment_arm` may not mean the same thing.** CGGA's is built from a radiotherapy flag
  and a chemotherapy flag; TCGA's comes from the TCGA ingest, a different source with
  different fields. The mix differs: 80 of 333 CGGA rows are `MonoTherapy` (24%) against
  57 of 594 in TCGA (10%).

### 4.3 Variant 3: 0.5915, but it cannot be compared with variant 2

Variant 3 scores **0.5915** (95% CI 0.5477 to 0.6341, n = 241, 204 deaths): 0.053 higher
than variant 2, with its whole interval below 0.65 as well. The tempting reading, "adding
IDH and MGMT recovers part of what KPS lost", is **not supported**, for two reasons that
were visible before the run:

1. **The variants are scored on different patients.** Variant 2 uses 283 CGGA patients.
   Variant 3 uses the 241 that also have both calls and no unseen category. A higher
   C-index on a smaller, differently selected set is not an improvement on the larger set.
2. **Twenty CGGA patients could not be scored by variant 3 at all.** All 20 are
   `NoAdjuvant`. No TCGA patient with both molecular calls had `NoAdjuvant` (section 3),
   so the model has no term for it, and the pre-specified rule excludes a category the
   TCGA fit never saw rather than coding it as the reference level. **Variant 3 is not
   evaluated on CGGA's no-adjuvant patients** and says nothing about them.

| | Variant 2 | Variant 3 |
| --- | --- | --- |
| Unique CGGA patients | 305 | 305 |
| Dropped: missing feature(s) | 21 (treatment_arm) | 44 |
| Dropped: missing outcome | 1 | 0 |
| Dropped: category unseen in the TCGA fit | 0 | 20 (`NoAdjuvant`) |
| **Evaluated** | **283** | **241** |
| Of which deaths | 239 | 204 |

A like-for-like comparison would score variant 2 on the same 241 patients. That was not
pre-specified and was not done: it would be a second, post-hoc read of the external set.

What variant 3 supports is narrower: on 241 CGGA patients who received adjuvant therapy
and have both marker calls, a TCGA-fitted model using age, sex, treatment arm, IDH and
MGMT shows external discrimination of 0.59, below the registered threshold, with an
interval that overlaps variant 2's.

## 5. The harmonisation caveat, in plain language

Variant 3 compares two things that look like the same two columns and are not.

- **In TCGA**, IDH and MGMT status come from this project's calling pipeline applied to
  TCGA's molecular data (`docs/mgmt_idh_calling.md`). They are available for 368 and 415
  of 594 patients; everyone else has no call.
- **In CGGA**, they are text fields in CGGA's own clinical spreadsheet
  (`IDH_mutation_status`, `MGMTp_methylation_status`), recorded by the contributing
  hospitals. The ingest does not establish which assay or threshold produced them. It maps
  `Mutant` to 1 and `Wildtype` to 0 and leaves anything else missing
  (`docs/cgga_ingestion.md` section 3).

So a "1" means "this project's pipeline called a mutation in TCGA data" on one side and
"a hospital recorded the tumour as IDH-mutant" on the other. Assays, thresholds and
platforms can differ. If CGGA's calls are noisier than TCGA's, variant 3 is penalised; if
cleaner, it is flattered. This evaluation cannot tell which.

**Variant 3's number is a cross-platform comparison and should be read as such.** It is
not evidence for or against IDH and MGMT as prognostic markers, and it is not the primary
T2 result.

## 6. What this means for T2, and what would change it

### 6.1 Status

**T2's C-index criterion is not met.** Two independent reasons, either sufficient:

1. The registered model (variant 1) cannot be evaluated on the registered external cohort,
   because CGGA has no KPS. Its external C-index does not exist.
2. The nearest evaluable model (variant 2) scores 0.5385, with the whole 95% interval
   below 0.65.

The pre-registration anticipated roughly this: its prior expectations name an external
survival C-index below 0.65 as the most likely result, and its risk register prescribes the
response to one. Report the achieved C-index with full defensibility, report the threshold
as FAIL rather than re-stating it, and re-frame the contribution as benchmark
establishment. Nothing in this document proposes moving the threshold.

The pre-registered response also asks for calibration (Brier score at 12, 18 and 24
months, calibration slope and intercept, decision-curve analysis). The Brier scores were
computed on the second read (section 12). Calibration slope and intercept and the
decision-curve analysis have not been done; on 2026-11-27 the decision was recorded not
to do them for this thesis (section 12.5).

### 6.2 A procedural gap the lead should know about

The pre-registration says final T2 numbers are reported on a **frozen external test
partition**, `cgga_external_v1`. It does not exist: `docs/preregistration.md` section 4.5
lists it as not yet created. This evaluation used the ingested CGGA cohort as instructed,
without a sealed manifest.

In substance CGGA had now been read. A second read followed the same day, for T2's Brier
row, which is itself a registered threshold (section 12). Any CGGA analysis beyond the
registered tests is a disclosed post-registration addition rather than a re-run.

### 6.3 Options for T2's status (listed, not chosen)

These are the project lead's decisions. Each changes something registered, so each would
need a dated, disclosed pre-registration amendment. They are not ranked.

- **Report T2 as failed for this model and keep the registration as written.** This is
  the option the risk register itself describes: benchmark establishment, threshold
  reported as FAIL. It needs no new data.
- **Amend the registered feature set to the transferable three features.** This does not
  rescue the result: variant 2 is that model, and it scored 0.5385. An amendment would
  make the registration match what can be evaluated, not make the threshold reachable.
- **Validate the committed four-feature model on a cohort that records performance
  status.** CGGA cannot supply KPS in any release, so "a larger CGGA cohort with KPS" is
  not an available option; only a different cohort can test variant 1 as registered. The
  pre-registration names GLASS as the longitudinal external cohort and CPTAC-GBM as a
  possible third. Whether either records KPS has not been checked here.
- **Reframe around a model whose primary features are molecular or expression-based.**
  That is a new model, not a re-evaluation of this one. It would need its own
  pre-registered external test on a partition that has not been read; CGGA has been.
- **Change the threshold.** Listed only to reject it. The pre-registration fixes 0.65 from
  published benchmarks before any external read, and its risk register says a missed
  threshold is reported as FAIL, not re-stated.

Not an option: re-running this evaluation on CGGA with tweaks (a different Cox configuration,
a patient subset, imputed KPS). Anything chosen because it scores better there is contaminated.

## 7. What this result does NOT prove

- **Not that clinical features lack prognostic value in CGGA.** A TCGA-fitted model
  failing to transfer is consistent with age, sex and treatment still mattering there.
- **Not that no Cox model can reach 0.65 on CGGA.** One specification, fitted on one
  cohort, was tested. Nothing else was tried, deliberately.
- **Not why the model failed to transfer.** Section 4.2 lists candidates. None was tested.
- **Not a calibration analysis.** Sections 1 to 8 measure discrimination only. The Brier
  scores are in section 12; no calibration slope or intercept was computed.
- **Not anything about IDH or MGMT as markers.** Variant 3 is cross-platform, scored on a
  selected subset, and excludes the no-adjuvant patients.
- **Not a precise estimate.** One external cohort of 305 unique patients, one model, one
  time point. The headline interval is about +/- 0.04 wide and contains 0.50. It reflects
  CGGA sampling only, not uncertainty in the TCGA fit.
- **Not insensitive to design choices.** Two were fixed in advance and not varied
  (section 8): one row per patient, and complete cases. A different pre-specified choice
  would give a different number. Testing that would be another read, so it was not done.

## 8. How the evaluation set was defined

Every rule here was written into the script and its tests before the first CGGA evaluation,
and none was changed afterwards.

**One row per patient.** CGGA reuses `CGGA_ID` across batches: 333 rows are 305 patients,
with 28 ids in two batches (`docs/cgga_ingestion.md` section 2). Scoring all 333 rows would
count those 28 twice. The first row in stored order was kept for each id. The rule is
deterministic and blind to every value; it is also arbitrary between a patient's two
records, and which record is kept was not examined.

This departs from the brief for this task, which described the evaluable set as 325 rows
with survival, or 311 with a treatment arm. On unique patients those counts are 297 and
284. The reason is the double-counting; the lead should confirm it is the intended
definition.

**Complete cases, nothing imputed, for variants 2 and 3 in both cohorts, and for every
variant on CGGA.** A patient missing any feature of the variant, or the outcome, is
excluded and counted. KPS is the limiting case: missing for every CGGA patient, so a
variant that uses it is not evaluable at all. Variant 1 is the exception, and only on the
TCGA side: it imputes KPS with a median and an indicator and the treatment arm with a
level (section 2.1). It is never scored on CGGA, where no value is imputed.

**An unseen category excludes the patient.** If a CGGA patient's categorical value never
occurred in the TCGA fit there is no coefficient for it. The patient is excluded and
counted, never silently coded as the reference level. This removed 20 patients from
variant 3 and none from variant 2.

**Encoding.** CGGA is encoded with the TCGA fit's reference levels and column order. A test
pushes the same rows through the training encoder and the external encoder and requires
identical matrices.

**Internal C-index.** Variant 1 is the committed `fit_clinical_baseline`: 5-fold
stratified CV on the 592 modelled patients, with KPS imputed by the training fold's
median (since 2026-11-27; before that by the median of all 592, which gave the same
number). Variants 2 and 3 use 5-fold stratified CV on the same complete-case TCGA rows
the external model is fitted on. These are internal numbers, not T2 results. No
difference between two of them carries an interval (section 4.2).

**Confidence interval.** Percentile bootstrap over the evaluated CGGA patients, 1000
resamples, seed 42, with the TCGA model held fixed. `clears_t2_threshold` is true only if
the point estimate and the lower bound are both >= 0.65.

## 10. Reproducing the numbers

```
python -m pytest tests/test_validate_cox_cgga.py -q     # synthetic + TCGA only
python scripts/validate_cox_cgga.py --dry-run           # no fit, no metric
python scripts/validate_cox_cgga.py                     # the evaluation
python -m pytest tests/test_validate_brier_cgga.py -q   # synthetic only
python scripts/validate_brier_cgga.py --dry-run         # no fit, no metric
python scripts/validate_brier_cgga.py                   # the Brier row, once
```

The script is deterministic (seed 42 throughout): re-running it reproduces the same
numbers and is not a new analysis. Anything else done with CGGA is.
`validate_brier_cgga.py` refuses to overwrite an existing result file; `--overwrite`
exists only for a deliberate, reported re-run.

Dependencies: `data/raw/cgga/clinical_cohort.parquet` (from `scripts/download_cgga.py`;
`data/raw/**` is not git-tracked, so a clean checkout must run that ingest first), the TCGA
cohort, and the joined TCGA calls from `scripts/join_molecular_calls.py`.

  set of patients (241 against 283), and it cannot be the primary result.
- **Same models as the C-index row.** The internal C-index of each TCGA fit is identical to
  the first run's (0.6520 and 0.6606, difference 0.0) and the evaluable counts are the same
  (283 and 241), so this row describes the models whose discrimination is in section 1.

### 12.2 What the score means

The Brier score at 18 months is the average squared error between each patient's predicted
probability of surviving 18 months and what happened. It runs from 0 (perfect) to 1; lower is
better. Patients censored before 18 months are handled by inverse-probability-of-censoring
weights. Of the 283 patients, 239 died and 123 were still alive and under observation at 18
months; the observed proportion alive at 18 months is 0.457.

- **The model is less accurate than predicting nothing about the individual.** A null model
  that predicts the cohort's own 18-month survival (0.457) for every patient scores 0.2481.
  The model scores 0.2617. Predicting the same number for everyone would have been closer.
- **This is consistent with the C-index, but does not say what causes it.** A C-index of
  0.5385 says the model barely ranks patients. A Brier score above the null model's says
  the predictions are worse than a constant. It does not say which of two things makes
  them so. With no resolution, the excess over the null model equals the squared offset
  (the mean predicted probability less the observed survival of 0.457, squared) plus the
  variance of the predictions. Poor ranking, meaning dispersion that does not match
  outcomes, can worsen the score on its own; so can an offset. The two cannot be told
  apart without a calibration or resolution analysis, and neither was done. So it is not
  known here which dominates, nor in which direction any offset points. An earlier version
  of this paragraph said the score "cannot come from poor ranking alone"; that was wrong.
- **In this cohort the threshold is close to the no-information level.** With 45.7% alive at
  18 months, the uninformative score is 0.457 x 0.543 = 0.248, just under the registered
  0.25. A model could have passed this row while discriminating not at all. The model did
  not pass it. The threshold is reported as registered and is not re-stated.

### 12.4 Rules fixed before this read

Every rule was written into the script and its tests, and the tests passed, before the
script was run on CGGA.

- **Patients.** Identical to the C-index row. The cohort rules are imported from
  `scripts/validate_cox_cgga.py` and are not re-implemented: one row per patient (333 rows
  are 305 patients), complete cases on the variant's features and the outcome, nothing
  imputed, and a categorical value unseen in the TCGA fit excludes the patient. For variant
  2 that excluded 21 patients with a missing feature and 1 with a missing outcome. For
  variant 3 it excluded 44 and 20 respectively. "Nothing imputed" holds for this row in
  both cohorts: only variants 2 and 3 are scored, and their TCGA fits are complete cases.
  Variant 1, which imputes on TCGA, is not in this row.
- **Models.** The same three variants, fitted on TCGA by the same `fit_variant`. Variant 2
  decides the verdict.
- **Score.** IPCW Brier score (Graf et al. 1999) as implemented in
  `gliostrata.prediction.cox.brier_score_ipcw`, with censoring weights from a Kaplan-Meier
  estimate on the evaluated CGGA patients.
- **Interval.** Percentile bootstrap over the evaluated CGGA patients, 1000 resamples, seed
  42. The model and every prediction are fixed; the censoring weights are re-estimated in
  each resample.
- **Verdict.** Computed by the pre-registered registry (`gliostrata.evaluation.thresholds`,
  key `T2_brier_18mo`), not by a comparison written in the script: PASS only if the point
  estimate and the CI upper bound are both <= 0.25.
- **Re-run guard.** The script refuses to overwrite an existing result file.

### 12.5 What was not done

- No calibration slope or intercept, no calibration plot, no decision-curve analysis. The
  pre-registered response to a missed T2 names them. Each would be a further look at CGGA
  and was not made.

  **Decision (2026-11-27): not done for this thesis.** Three reasons. Calibration is not a
  registered row: none of the eleven thresholds in section 2 of the pre-registration is a
  calibration measure, so nothing that decides T2 turns on it. A further read would not
  change the T2 verdict, which is FAIL on the C-index and Brier rows from the data already
  read. And the question a calibration analysis would answer, whether the Brier excess
  comes from an offset or from dispersion, is named as a limitation (section 12.2) instead
  of being left implicit. This is a project decision, not an amendment: it changes no
  threshold, no decisive bound and no decision rule. A reader who wants the analysis can
  have it only as a new, separately pre-registered exploratory read of CGGA.
- No change to the model, the features, the horizon, the threshold or the interval.
- No read of a sealed `cgga_external_v1` partition. Like the first read, this one ran on the
  ingested cohort as a whole, because no sealed partition exists yet.

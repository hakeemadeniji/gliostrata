# Result figures

Generated by `scripts/t4t5_figures.py`, drawn from committed result files and never from
numbers typed into the script, so a figure cannot disagree with the record it illustrates.
Regenerate with `python scripts/t4t5_figures.py all`.

Each figure ships three files: a **PDF** (vector, for submission), a **PNG** at 300 dpi (for
preview), and a **CSV** of its own numbers.

| Figure | Shows | Source |
|---|---|---|
| `t4t5_emax_forest` | every study's effect ratio by payload, the registered median, and which studies item 11(i.7) excludes | `emax_result.json`, `extraction_final.jsonl` |
| `t4t5_dose_response` | the registered dose-response per payload, with ED50 and the registered dose range | `configs/response_surface_v1.yaml` |
| `t4t5_survival_gain` | what an RMST gain is the area of | parameter file |
| `t4t5_rehearsal_gains` | per-patient gains from the item 11(o) rehearsal against T5's thresholds | `docs/dry_runs/t4t5_controls.json` |

## The visual system

`src/gliostrata/reporting/figures.py` holds it, so no script picks its own colours and a hue
means the same thing in every panel.

**The palette was validated, not chosen.** Three categorical slots, checked on the all-pairs
list because these figures put all three series on screen together:

| Check | Result |
|---|---|
| Lightness band | PASS |
| Chroma floor | PASS |
| Colour-vision separation | PASS, worst pair ΔE 12.6 deutan / 10.8 tritan (target ≥ 8) |
| Normal-vision floor | PASS, worst pair ΔE 23.0 (floor ≥ 15) |
| Contrast vs surface | **WARN** — orange 2.88, aqua 2.54, both below 3:1 |

That WARN is an obligation, not a preference: a palette below 3:1 must ship visible direct
labels **or** a table view. Both are provided — every figure direct-labels its series, and
every figure writes its CSV. Each series also carries a distinct marker, so identity never
rests on colour alone in print, under colour-blindness, or in a photocopy.

## Rules these figures hold to

- Categorical hues are assigned **in fixed order and never cycled**. A fourth payload would
  need a facet, not a generated hue — `payload_style` raises rather than inventing one.
- **Colour follows the entity.** Blue means CRAd everywhere. The rehearsal-gains figure is
  deliberately *not* on the payload palette, because its rows are runs, not payloads.
- **One axis.** No chart here has two y-scales.
- Grid and axis rules are **solid hairlines**. Dashing is reserved for a real threshold —
  T5's 3-month bar, the harm line, the no-effect line — where it carries meaning.
- Text wears text inks, never a series colour.
- Values are direct-labelled **selectively**; no figure puts a number on every point.
